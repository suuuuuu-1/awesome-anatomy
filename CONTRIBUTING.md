# Contributing

Found an Anatomy work we missed? [Send its original link](https://github.com/suuuuuu-1/awesome-anatomy/issues/new?template=submit-work.yml). The source URL is the only required field. You do not need to prepare a pull request, find the code, or supply a full prompt.

If you have them, these details help:

- A short title and one sentence explaining what the work shows.
- The original creator and source post or page.
- A live example, preview, source code or published prompt when available.
- Known format, reuse terms and any missing resource links.

We collect works made with Anatomy or a credited derivative. A general AI animation, a model name, or the word “anatomy” in a title is not enough on its own. Link the creator's Anatomy credit, project README or other original evidence when available.

A demonstration-only work is welcome when clearly labeled. Do not invent prompts, duplicate reposts, count color themes as separate works, or claim a work was tested when it was not. Keep third-party media at its existing source unless its author permits redistribution.

For corrections or removal requests, identify the entry and the original creator.

For pull requests, update the matching record in `data/entries.json`, keep the English and Chinese catalogs consistent, and preserve existing IDs. A work can have several original URLs or themes without becoming several entries. Keep counts and prompt pages in sync; published prompt text must match its source. You can also open an issue and leave the catalog updates to the maintainer.
